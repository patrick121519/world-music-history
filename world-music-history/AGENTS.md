# AGENTS.md — World Music History

## 專案定位
本專案是「World Music History｜世界音樂歷史博物館」，以繁體中文呈現跨文化、跨地域的音樂歷史。網站目標是讓一般讀者能按年代、地域、流派與人物探索音樂如何在不同社會中形成、交流與演變。

## 核心開發原則
1. **全球視角**：不可把西方古典音樂或美國流行音樂寫成唯一的音樂史。內容應適度涵蓋非洲、亞洲、歐洲、美洲、中東與大洋洲的傳統及當代音樂。
2. **脈絡優先**：介紹流派時，說明其地域與社會背景、音樂特徵、傳播方式、重要影響；避免只列名詞或人物。
3. **避免單一起源論**：音樂風格通常由多種傳統互相影響而形成。對起源有爭議或年代不確定的內容，使用「約」、「常見說法」、「逐步形成」等審慎措辭。
4. **資料可追溯**：新增歷史事實時，優先引用博物館、學術機構、圖書館、UNESCO、音樂史研究與可靠百科資料。每個新增內容區塊盡可能附上可查證來源連結；不可捏造引文、年份或來源。
5. **尊重文化脈絡**：使用各文化社群較常見的自稱與正確拼寫；避免把不同地區的傳統混為一談，避免將傳統音樂描述成停滯不變。
6. **版權安全**：不得直接複製受著作權保護的長篇文章、歌詞、唱片封面或未授權照片。優先使用自行撰寫文字、CSS/SVG 圖像與明確授權素材，並標示授權。

## 技術架構
- 純 HTML、CSS、原生 JavaScript；不使用建置工具、伺服器或外部套件。
- `index.html`：首頁與導覽入口。
- `timeline.html`：可篩選的音樂歷史時間軸。
- `eras.html`：依歷史時期瀏覽。
- `genres.html`：跨地域音樂流派索引。
- `people.html`：音樂人物小傳。
- `assets/styles.css`：全站共用樣式。
- `assets/data.js`：共用內容資料。
- `assets/app.js`：導覽、搜尋、篩選與互動。
- 網站必須可由 GitHub Pages 直接以靜態檔案方式部署。

## 設計系統
- 視覺方向：深色典藏博物館、編輯式排版、低飽和金色點綴。
- 色彩：背景以墨黑／深炭灰為主，文字使用暖白，金色僅作為重點；確保對比度與可讀性。
- 排版：使用系統字體堆疊，不依賴遠端字體才能正常顯示。
- 元件：頁首導覽、標題區、內容卡、時間軸、來源區、頁尾應維持一致。
- 響應式：至少支援 360px 手機寬度、平板與桌面；不可出現水平溢位。
- 無障礙：語意化 HTML、可見焦點、鍵盤可操作、表單有標籤、圖片有替代文字。

## 新增或修改內容的規則
1. 新增頁面時，沿用現有頁首、導覽、頁尾與設計 token，不另創不一致的風格。
2. 新增年代或事件時，應同步考慮是否要加入 `assets/data.js`、首頁精選內容與時間軸。
3. 新增流派時，至少提供：主要地域／文化脈絡、形成背景、聲音或演奏特徵、代表人物或社群、後續影響。沒有可靠資料時明確標示待查，不可自行補造。
4. 新增人物時，至少提供：姓名、年代／地域、角色、重要貢獻；人物選例需兼顧不同地域與性別，不宣稱「唯一」或「最偉大」除非有明確脈絡。
5. 搜尋與篩選需支援繁體中文及英文名稱的基本比對。
6. JavaScript 必須漸進增強：若 JS 未載入，主要文字內容仍可閱讀。
7. 外部連結使用完整 HTTPS URL，並在適當情況加上 `rel="noopener noreferrer"`。
8. 不加入自動播放音訊／影片；若未來加入音訊，必須由使用者明確操作才播放。
